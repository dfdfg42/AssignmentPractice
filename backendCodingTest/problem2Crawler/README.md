# 문제 2. 고성능 크롤러

> 지문은 구현 코드에서 역추적해 다시 쓴 것이다. 원본과 다를 수 있다.

## 지문

URL 목록을 받아 각 페이지의 본문을 파일로 저장하는 크롤러를 만든다.

**입력**: 표준 입력으로 URL이 한 줄에 하나씩 들어온다. 최대 1만 개.

**요구사항**:

- i번째 URL의 응답 본문을 `i.html` 파일로 저장한다 (1부터 시작).
- 요청이 실패하면(2xx가 아닌 응답, 타임아웃, 네트워크 오류) 파일 내용을 `FAILED`로 저장한다.
- URL 하나에 1초만 걸려도 순차 처리로는 1만 개에 3시간 가까이 걸린다. 전체가 현실적인 시간 안에 끝나야 한다.

## 실행

```bash
./gradlew run < urls.txt
```

`urls.txt`는 한 줄에 URL 하나. 결과는 현재 폴더에 `1.html`, `2.html`, … 로 저장된다.

## 풀이 요약

고정 크기 스레드풀(`ExecutorService`, 50개)에 URL별 작업을 제출하고 `Future.get()`으로 전부 끝날 때까지 기다린다. 연결·요청 타임아웃은 10초. 어떤 예외가 나도 해당 파일에 `FAILED`를 쓰고 다른 작업에 영향을 주지 않는다.

| 파일 | 역할 |
|---|---|
| `Crawler.java` | stdin 읽기, 스레드풀 제출, 파일 저장 |
