# 문제 1. 카드 조합 비교

> 지문은 구현 코드에서 역추적해 다시 쓴 것이다. 원본과 다를 수 있다.

## 지문

두 플레이어가 각각 숫자 카드 5장을 들고 있다. 각 플레이어의 카드 조합 등급을 판정해 누가 이기는지 출력한다.

**입력**: 한 줄. 쉼표로 두 플레이어의 손패를 구분하고, 각 손패는 공백으로 구분된 정수 5개.

```
3 3 3 2 2, 1 2 3 4 5
```

**조합 등급** (높은 순):

1. 파이브 카드: 같은 숫자 5장
2. 스트레이트: 서로 다른 숫자 5개가 연속
3. 포 카드: 같은 숫자 4장
4. 풀 하우스: 같은 숫자 3장 + 같은 숫자 2장
5. 투 페어: 같은 숫자 2장이 두 쌍
6. 그 외

**출력**: 첫 번째 플레이어의 등급이 높으면 `First`, 두 번째가 높으면 `Second`, 등급이 같으면 `Draw`. 같은 등급끼리 숫자 크기는 비교하지 않는다.

## 실행

```bash
./gradlew run
# 입력: 3 3 3 2 2, 1 2 3 4 5
# 출력: Second   (풀 하우스 < 스트레이트)
```

## 풀이 요약

카드 숫자별 빈도수를 내림차순으로 정렬하면 조합이 바로 드러난다. `[5]`는 파이브 카드, `[4,1]`은 포 카드, `[3,2]`는 풀 하우스, `[2,2,1]`은 투 페어. 스트레이트는 숫자 종류가 5개이고 최대-최소가 4일 때다. 등급은 `HandRank` enum 선언 순서(`compareTo`)로 비교한다.

| 파일 | 역할 |
|---|---|
| `CardHandJudge.java` | 입력 파싱, 등급 판정, 승패 출력 |
| `HandRank.java` | 등급 enum (선언 순서가 곧 우선순위) |
